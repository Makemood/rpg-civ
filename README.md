# River — анализатор раздач GGPoker

Основное приложение находится в `hand-analyzer/`. Корневая страница открывает анализатор.

Запуск без установки зависимостей: `npm run dev` (нужен Python 3), либо `python3 hand-analyzer/launch.py` с автоматическим открытием браузера. Загрузите свою историю TXT/ZIP через приложение. Личные раздачи не включены в репозиторий.

- `npm test` — тесты парсера, практических советов и профилей соперников.
- `npm run build` — статический сайт в `dist/`, без зависимостей и без личных файлов.
- `npm run preview` — локальная проверка собранного сайта.

GitHub Actions проверяет pull request и при push в `master` публикует сборку в ветку `gh-pages`. Для сайта GitHub Pages в настройках репозитория должен быть выбран источник `gh-pages`, корневая папка. Netlify использует `npm run build` и `dist`.

Обновление в отдельной ветке ещё не обновляет `master` и опубликованный сайт. После слияния проверьте завершение workflow развёртывания.

В исходниках `src/` сохранён прежний прототип RPG; он не входит в текущую сборку анализатора. Подробности функций и ограничений — в [hand-analyzer/README.md](hand-analyzer/README.md).
