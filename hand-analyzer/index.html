Практические советы

Приложение не рассчитывает GTO, эквити против неизвестных диапазонов или ICM. Пропущенные открытия и «слишком широкий колл» не объявляются ошибками без подходящего диапазона. Flip & Go исключены из рекомендаций.

Как определяется тип и какие есть ограничения

Автометка появляется от 100 наблюдаемых раздач: «похож на кита» — VPIP ≥65% и разрыв VPIP/PFR ≥35 п.п.; «похож на фиша» — VPIP ≥40% и разрыв ≥20 п.п.; «похож на рега» — VPIP 15–32%, PFR ≥12%, разрыв ≤8 п.п. Это простые шаблоны стиля, не доказательство силы или прибыльности. За пределами шаблонов тип не определяется.

Профиль считается отдельно для имени внутри каждого турнира: анонимные имена GGPoker нельзя надёжно объединять между турнирами. Используется вся история выбранной группы для анализа после игры. Ручная метка имеет приоритет; при закрытии страницы или очистке истории метки теряются.

05 / БИБЛИОТЕКА ДИАПАЗОНОВ

Префлоп-диапазоны

Скачивание с GTO Wizard пока недоступно: HTTP 403. Диапазоны не загружены. Здесь можно просмотреть импортированный чарт; автоматическое сравнение с раздачей не выполняется.

Нельзя оценивать все баунти-раздачи одним чартом: нужны позиция, стек, анте, действие соперников и модель наград.

Формат импорта
{
  "source": "Название источника / версия решения",
  "context": "8-max, PKO, 25bb, ante 0.125bb, BTN RFI; модель наград…",
  "hands": {"AA": 1, "AKs": 0.75, "AKo": 0.5}
}

Частоты от 0 до 1. Это пример структуры файла, а не GTO-диапазон. Пропущенные руки отображаются как «нет данных», а не как фолд.
